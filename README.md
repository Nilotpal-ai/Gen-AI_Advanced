# Gen-AI_Advanced
Generative AI-Powered Retrieval-Augmented QA over Insurance PDFs with Discord Frontend

## 🚀 Features

- 📚 PDF ingestion and preprocessing
- 🔍 Hybrid search:
  - Fuzzy keyword matching
  - Semantic vector search (Qdrant)
- 🤖 LLM-powered answer generation (context-restricted)
- ⚡ FastAPI backend
- 💬 Discord bot frontend
- 🐳 Docker support for Qdrant
- 🔐 Environment-based configuration
